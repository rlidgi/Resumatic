# Flask Integration Guide

This guide shows you how to integrate the Resume Builder into your Flask application at the `/create-resume` route.

## Prerequisites

- Node.js and npm/pnpm installed
- Your existing Flask application with a landing page at `/` (index.html)

## Your Project Structure

Based on your existing codebase (with root-level package.json and vite.config.ts):
```
your-project/
├── package.json              # Root (existing)
├── vite.config.ts            # Root (existing)
├── index.html                # Root (create this)
├── frontend/
│   └── src/
│       ├── app/              # Resume builder components (from this code)
│       ├── styles/           # CSS files
│       ├── imports/          # Template thumbnails
│       └── main.tsx          # Entry point
├── app.py (or your Flask app)
├── templates/
│   └── index.html            # Your landing page
├── static/
│   └── resume-builder/       # Built files go here
└── dist/                     # Generated by build (gitignore this)
```

## Setup Steps

### 1. Copy Resume Builder Code

Copy the following from this codebase to your project:

- `src/app/` → `frontend/src/app/`
- `src/styles/` → `frontend/src/styles/`
- `src/imports/` → `frontend/src/imports/`
- `src/main.tsx` → `frontend/src/main.tsx`

### 2. Create index.html in Project Root

In your project root (same level as package.json), create `index.html`:

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Resume Builder</title>
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="/frontend/src/main.tsx"></script>
  </body>
</html>
```

### 3. Update package.json

Merge these dependencies into your root `package.json`:

```json
{
  "dependencies": {
    "@radix-ui/react-accordion": "1.2.3",
    "@radix-ui/react-label": "2.1.2",
    "@radix-ui/react-slot": "1.1.2",
    "class-variance-authority": "0.7.1",
    "clsx": "2.1.1",
    "lucide-react": "0.487.0",
    "react": "18.3.1",
    "react-dom": "18.3.1"
  },
  "devDependencies": {
    "@tailwindcss/vite": "4.1.12",
    "@vitejs/plugin-react": "4.7.0",
    "tailwindcss": "4.1.12",
    "vite": "6.3.5"
  }
}
```

### 4. Update vite.config.ts

Add/merge these settings into your root `vite.config.ts`:

```typescript
export default defineConfig({
  // ... your existing config
  
  build: {
    outDir: 'dist',
    assetsDir: 'assets',
    emptyOutDir: true,
  },
  
  base: '/create-resume/',
})
```

### 5. Build the Project

Run the build command from your project root:

```bash
npm install  # Install new dependencies if needed
npm run build
```

This will create a `dist/` folder in your project root.

### 6. Copy Built Files to Flask Static Folder

Copy the contents of `dist` to your Flask static directory:

```bash
# From your project root
cp -r dist/* static/resume-builder/
```

Your Flask project structure should now look like:

```
your-project/
├── package.json
├── vite.config.ts
├── index.html
├── frontend/
│   └── src/
│       ├── app/
│       ├── styles/
│       └── main.tsx
├── dist/              # Build output (generated, gitignore this)
├── app.py
├── static/
│   └── resume-builder/    # Copied from dist
│       ├── index.html
│       └── assets/
└── templates/
    └── index.html         # Your existing landing page
```

### 7. Flask Route Configuration

Add these routes to your Flask application:

```python
from flask import Flask, send_from_directory, abort
import os

app = Flask(__name__)

# Your existing landing page route
@app.route('/')
def home():
    return render_template('index.html')  # Your existing landing page

# Resume builder route
@app.route('/create-resume')
def create_resume():
    return send_from_directory('static/resume-builder', 'index.html')

# Serve resume builder static assets
@app.route('/create-resume/<path:path>')
def serve_resume_assets(path):
    # Prevent directory traversal
    if '..' in path or path.startswith('/'):
        abort(404)
    
    file_path = os.path.join('static/resume-builder', path)
    if os.path.isfile(file_path):
        return send_from_directory('static/resume-builder', path)
    abort(404)

if __name__ == '__main__':
    app.run(debug=True)
```

### 8. Update Your Landing Page

Add a link from your landing page (index.html) to the resume builder:

```html
<a href="/create-resume">Create Your Resume</a>
```

## Important Notes

1. **Base Path**: The vite config is set to `base: '/create-resume/'` to ensure all asset paths are correct when served from Flask.

2. **Static Files**: Make sure Flask can serve the static files. The resume builder needs to load:
   - JavaScript bundles
   - CSS files
   - Template thumbnail images from `/imports/`

3. **Development vs Production**:
   - For development, you can run `pnpm dev` and proxy from Flask
   - For production, always run `pnpm build` after making changes

4. **Rebuilding**: Whenever you make changes to the React code:
   ```bash
   # From project root
   npm run build
   # Then copy dist/* to static/resume-builder/
   cp -r dist/* static/resume-builder/
   ```

## Alternative: Serving from CDN or Separate Domain

If you prefer, you can serve the built files from a CDN or separate subdomain, and just link to it from your landing page. In this case, update `vite.config.ts` to remove the `base` configuration.

## Troubleshooting

### Assets Not Loading
- Check that the Flask route `/create-resume/<path:path>` is correctly serving files
- Verify the `dist` folder was copied to the correct location
- Check browser console for 404 errors

### Blank Page
- Open browser console to check for JavaScript errors
- Verify `index.html` has the correct `<div id="root"></div>`
- Ensure React scripts are loading correctly

### Images Not Showing
- Check that the `imports` folder from `dist` was copied
- Verify Flask is serving files from the correct directory
- Check browser Network tab for 404s on image files
